# JAVA-Problems-and-Refractory
Common , medium and Advanced Java Problems. Refactoring added to the mix.

Refactoring makes the code easier to work with and far easier to extend. Making this a solid approach when dealing with the creation of complex systems.

The code tried to follow and fix: common bad smells, extract classes and methods, replace complicated constructors with methods, simplify conditionals with polymorphism , eliminate duplicates with template methods, use different construction patterns and more.
